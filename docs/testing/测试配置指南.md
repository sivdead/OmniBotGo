## CI/CD配置

### 1. GitHub Actions

#### 基础测试流水线
```yaml
# .github/workflows/test.yml
name: Tests

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest
    
    services:
      mysql:
        image: mysql:8.0
        env:
          MYSQL_ROOT_PASSWORD: password
          MYSQL_DATABASE: testdb
        ports:
          - 3306:3306
        options: >-
          --health-cmd="mysqladmin ping"
          --health-interval=10s
          --health-timeout=5s
          --health-retries=3
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up Go
      uses: actions/setup-go@v3
      with:
        go-version: 1.21
    
    - name: Cache Go modules
      uses: actions/cache@v3
      with:
        path: ~/go/pkg/mod
        key: ${{ runner.os }}-go-${{ hashFiles('**/go.sum') }}
        restore-keys: |
          ${{ runner.os }}-go-
    
    - name: Install dependencies
      run: |
        go mod download
        go install github.com/golang/mock/mockgen@latest
        go install github.com/google/wire/cmd/wire@latest
    
    - name: Generate code
      run: |
        go generate ./...
        wire ./internal/app
    
    - name: Run tests
      run: |
        go test -v -race -coverprofile=coverage.out ./internal/...
    
    - name: Run integration tests
      run: |
        go test -v ./integration-test/...
      env:
        DB_HOST: localhost
        DB_PORT: 3306
        DB_USER: root
        DB_PASSWORD: password
        DB_NAME: testdb
    
    - name: Upload coverage to Codecov
      uses: codecov/codecov-action@v3
      with:
        file: ./coverage.out
        flags: unittests
        name: codecov-umbrella
```

#### 多版本测试

```yaml
strategy:
```

### 2. 测试脚本

#### 本地测试脚本
```bash
#!/bin/bash
# scripts/test.sh

set -e

echo "🧪 运行OmniBotGo测试套件"

# 检查环境
echo "📋 检查环境..."
go version
which mockgen || (echo "❌ mockgen未安装" && exit 1)
which wire || (echo "❌ wire未安装" && exit 1)

# 生成代码
echo "🔧 生成代码..."
go generate ./...
wire ./internal/app

# 运行单元测试
echo "🧪 运行单元测试..."
go test -v -race -coverprofile=coverage.out ./internal/...

# 运行集成测试
echo "🔗 运行集成测试..."
if docker-compose -f docker/docker-compose-test.yml up -d; then
    sleep 10  # 等待服务启动
    go test -v ./integration-test/...
    docker-compose -f docker/docker-compose-test.yml down
else
    echo "⚠️  跳过集成测试（Docker不可用）"
fi

# 生成覆盖率报告
echo "📊 生成覆盖率报告..."
go tool cover -html=coverage.out -o coverage.html
echo "📊 覆盖率报告已生成: coverage.html"

# 运行静态分析
echo "🔍 运行静态分析..."
golangci-lint run

echo "✅ 所有测试完成！"
```

## 故障排除

### 1. 常见问题

#### Mock生成失败
```bash
# 检查mockgen版本
mockgen -version

# 重新安装mockgen
go install github.com/golang/mock/mockgen@latest

# 清理并重新生成
rm -f internal/usecase/mocks_*_test.go
go generate ./internal/usecase/
```

#### 数据库连接失败
```bash
# 检查数据库服务状态
docker-compose -f docker/docker-compose-test.yml ps

# 查看数据库日志
docker-compose -f docker/docker-compose-test.yml logs mysql

# 重启数据库服务
docker-compose -f docker/docker-compose-test.yml restart mysql
```

#### 测试超时
```bash
# 增加测试超时时间
go test -timeout 60s ./internal/...

# 检查是否有死锁
go test -race ./internal/...
```
