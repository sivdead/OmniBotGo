# 钉钉企业应用适配器实现总结

## 📅 完成时间
2024-01-11

## 🎯 任务目标
增强钉钉适配器，支持企业内部应用的消息收发

## ✅ 实现内容

### 1. 钉钉企业应用适配器 (`internal/adapter/dingtalk_enterprise/`)

#### 核心功能
- **Access Token管理**：自动获取和缓存Access Token，支持自动刷新
- **工作通知发送**：支持向指定用户发送工作通知
- **群消息发送**：支持向企业群发送消息
- **Webhook事件接收**：支持接收和解析企业应用的事件回调
- **多种消息类型支持**：文本、Markdown、卡片、链接、图片、文件、图文消息

#### 支持的事件类型
- 组织架构事件（用户入职/离职、部门变更）
- 应用事件（用户激活/停用应用）
- 审批事件（审批任务/实例变更）
- 考勤事件（打卡、考勤结果）
- 日程事件

### 2. 钉钉代理适配器 (`internal/adapter/dingtalk_proxy/`)

#### 设计思路
- 根据配置自动选择使用Stream模式还是企业应用模式
- Stream模式：配置了`client_id`和`client_secret`
- 企业应用模式：配置了`app_key`、`app_secret`和`agent_id`

#### 实现的接口
- `PlatformIdentifier`：平台标识
- `ConfigValidator`：配置验证
- `TokenManager`：Token管理（企业应用模式）
- `MessageSender`：消息发送
- `WebhookProcessor`：Webhook处理（企业应用模式）
- `StreamAdapter`：Stream连接（Stream模式）

### 3. 配置支持

#### 企业应用模式配置
```yaml
app_key: "your_app_key"          # 必填：应用AppKey
app_secret: "your_app_secret"    # 必填：应用AppSecret
agent_id: "your_agent_id"        # 必填：应用AgentID
corp_id: "your_corp_id"          # 可选：企业ID
message_mode: "work_notice"      # 可选：默认消息模式
webhook_token: "your_token"      # 可选：Webhook验证Token
aes_key: "your_aes_key"          # 可选：消息加密密钥
```

#### Stream模式配置（保持不变）
```yaml
client_id: "your_client_id"        # 必填：Stream客户端ID
client_secret: "your_client_secret" # 必填：Stream客户端密钥
```

## 🔧 技术细节

### 1. 依赖注入架构
- 使用Wire进行依赖注入
- 三个适配器分别注册：Stream适配器、企业应用适配器、代理适配器
- AdapterRegistry中只注册代理适配器，实现自动路由

### 2. 消息格式转换
- 统一消息模型与钉钉消息格式的双向转换
- 支持结构化消息内容（MarkdownMessage、CardMessage等）
- 兼容RawContent中的原始格式

### 3. 错误处理
- API调用错误的详细错误信息
- Access Token过期自动刷新
- 网络超时处理（30秒）

### 4. 性能优化
- Access Token缓存机制
- 并发安全的Token管理
- HTTP客户端复用

## 📝 使用示例

### 发送工作通知
```go
message := &dto.UnifiedMessage{
    MessageType:  entity.MessageTypeText,
    Content:      "这是一条工作通知",
    ReceiverID:   "user123",
    ReceiverType: entity.ReceiverTypeUser,
}

err = adapter.SendMessage(ctx, message, config, accessToken)
```

### 发送群消息
```go
message := &dto.UnifiedMessage{
    MessageType:  entity.MessageTypeMarkdown,
    MarkdownContent: &entity.MarkdownMessage{
        Title:   "项目进度",
        Content: "## 本周完成\n- 任务1\n- 任务2",
    },
    ReceiverID:   "chat123",
    ReceiverType: entity.ReceiverTypeGroup,
}
```
