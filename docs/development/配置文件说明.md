# 配置文件说明

## 配置文件结构

本项目使用YAML格式的配置文件，支持多环境配置：

- `config.yaml.example` - 配置文件模板（提交到版本控制）
- `config.yaml` - 实际配置文件（不提交到版本控制）
- `config.local.yaml` - 本地开发配置（不提交到版本控制）

## 快速开始

1. 复制配置模板：
```bash
cp config.yaml.example config.yaml
```

2. 编辑 `config.yaml` 文件，填入实际的配置值：
```yaml
# 数据库配置
db:
  dsn: "your_username:your_password@tcp(localhost:3306)/your_database?charset=utf8mb4&parseTime=True&loc=Local"

# RabbitMQ 配置
rmq:
  url: "amqp://your_username:your_password@localhost:5672/"
```

## 配置项说明

### 应用程序配置
- `app.name`: 应用程序名称
- `app.version`: 应用程序版本

### HTTP服务器配置
- `http.port`: HTTP服务器端口
- `http.use_prefork_mode`: 是否使用预分叉模式

### 数据库配置
- `db.type`: 数据库类型（目前支持mysql）
- `db.dsn`: 数据库连接字符串
- `db.max_connections`: 最大连接数

### gRPC服务器配置
- `grpc.port`: gRPC服务器端口

### RabbitMQ配置
- `rmq.server_exchange`: 服务端交换器名称
- `rmq.client_exchange`: 客户端交换器名称
- `rmq.url`: RabbitMQ连接URL

### 日志配置
- `log.level`: 日志级别（debug, info, warn, error）

### 监控配置
- `metrics.enabled`: 是否启用指标监控

### Swagger文档配置
- `swagger.enabled`: 是否启用Swagger文档

## 安全注意事项

⚠️ **重要**: 
- 不要将包含敏感信息的 `config.yaml` 提交到版本控制系统
- 生产环境配置应该通过环境变量或安全的配置管理系统提供
- 确保配置文件的文件权限设置正确

## 环境变量支持

应用程序也支持通过环境变量覆盖配置项，环境变量名格式为：`APP_<SECTION>_<KEY>`

例如：
```bash
export APP_DB_DSN="mysql://user:pass@localhost/db"
export APP_HTTP_PORT="9090"
```
