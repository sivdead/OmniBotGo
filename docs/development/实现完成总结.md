## 使用示例

### 1. 创建机器人
```bash
curl -X POST http://localhost:8080/api/v1/bots \
  -H "Content-Type: application/json" \
  -d '{
    "name": "测试机器人",
    "description": "用于测试的机器人",
    "avatar_url": "https://example.com/avatar.png"
  }'
```

### 2. 创建通道
```bash
curl -X POST http://localhost:8080/api/v1/channels \
  -H "Content-Type: application/json" \
  -d '{
    "bot_id": "bot_123",
    "platform": "wecom",
    "name": "企业微信通道",
    "config": {
      "app_id": "your_app_id",
      "secret": "your_secret",
      "corp_id": "your_corp_id"
    }
  }'
```

### 3. 发送消息
```bash
curl -X POST http://localhost:8080/api/v1/messages/send \
  -H "Content-Type: application/json" \
  -d '{
    "channel_id": "channel_123",
    "to_user_id": "user_456",
    "message_type": "text",
    "content": "Hello, World!"
  }'
```

### 4. 获取消息历史
```bash
curl "http://localhost:8080/api/v1/messages/history?channel_id=channel_123&page=1&page_size=20"
```
